# Санҷиши сканери штрихкод дар телефон (HTTPS дар шабакаи маҳаллӣ)

Мақсад: CRM-ро аз телефони Android ё iPhone бо **HTTPS-и боэътимод** кушоед, то камера кор кунад, штрихкодро скан кунед ва фурӯши аввалинро анҷом диҳед.

> Ин дастур барои санҷиши **маҳаллӣ** (dev/staging) аст. Production deployment нест.

## 0. Чаро HTTPS лозим аст

Браузери телефон камераро танҳо дар саҳифаи **HTTPS** (ё `localhost`) мекушояд. `http://192.168.x.x:5173` аз телефон кор **намекунад**.
Роҳи мо: сертификати маҳаллӣ бо `mkcert`. Он як «CA-и маҳаллӣ» месозад. Шумо ин CA-ро ҳам дар Windows ва ҳам дар телефон **эътимодшуда** мекунед. Танҳо self-signed кофӣ нест: телефон бояд ба он эътимод дошта бошад.

## 1. Дар Windows (як бор)

1. **IP-и компютерро донед.** Дар PowerShell: `ipconfig`. Дар қисми Wi-Fi хати «IPv4-адрес» (мисол: `192.168.1.23`) -ро нависед. Телефон бояд ба **ҳамон Wi-Fi** пайваст бошад (на Wi-Fi-и меҳмонон).
2. **mkcert-ро насб кунед:**
   ```powershell
   winget install FiloSottile.mkcert
   ```
   Баъд PowerShell-ро пӯшед ва дубора кушоед.
3. **CA-и маҳаллиро ба Windows илова кунед:**
   ```powershell
   mkcert -install
   ```
   Windows огоҳии амниятӣ мепурсад, «Yes» -ро пахш кунед.
4. **Сертификатро барои IP-и худ созед** (IP-и худро ҷойгир кунед):
   ```powershell
   cd C:\Users\Asus\ToolShopCRM\frontend\toolshop-client
   mkdir .certs
   mkcert -cert-file .certs\lan.pem -key-file .certs\lan-key.pem 192.168.1.23 localhost 127.0.0.1
   ```
   Папкаи `.certs` дар Git **нест** (дар `.gitignore` аст). Калидро ба касе нафиристед.
5. **Файли CA-ро ёбед:**
   ```powershell
   mkcert -CAROOT
   ```
   Ин папкаро нишон медиҳад. Дар он `rootCA.pem` ҳаст. Ба телефон **танҳо `rootCA.pem`** -ро фиристед. Файли `rootCA-key.pem` -ро **ҳаргиз** ба касе надиҳед ва ба телефон нафиристед.
6. **Дарвозаи Windows Firewall-ро кушоед** (PowerShell «Run as administrator»):
   ```powershell
   New-NetFirewallRule -DisplayName "ToolShop dev 5173" -Direction Inbound -Protocol TCP -LocalPort 5173 -Action Allow -Profile Private
   ```
   Агар шабакаи Wi-Fi дар Windows «Public» бошад, онро «Private» кунед (Settings → Network & internet → Wi-Fi → хосиятҳо → Network profile type → Private).

## 2. Дар телефон: ба CA эътимод кунед (як бор)

`rootCA.pem`-ро ба телефон бифиристед (кабели USB, Telegram «Saved Messages», Google Drive ё email ба худатон).

### Android (Chrome)
1. Файлро дар телефон ба `rootCA.crt` тағйир ном диҳед (баъзе Android-ҳо `.pem`-ро намебинанд).
2. **Settings → Security (Амният) → More security settings / Encryption & credentials → Install a certificate → CA certificate.** Агар ёфт нашуд, дар ҷустуҷӯи Settings «CA certificate» нависед.
3. «Install anyway» -ро интихоб кунед ва файли `rootCA.crt` -ро нишон диҳед.
4. Огоҳии «шабакаро метавон назорат кард» оддӣ аст (ин CA-и худи шумост).

### iPhone (Safari)
1. `rootCA.pem`-ро ба iPhone фиристед (AirDrop ё email). Онро кушоед: «Profile Downloaded».
2. **Settings → дар боло «Profile Downloaded» → Install** (рамзи телефонро ворид кунед).
3. **Муҳим:** **Settings → General → About → Certificate Trust Settings** -ро кушоед ва тугмаи «mkcert …»-ро **фаъол** кунед (Full trust). Бе ин қадам iPhone ба сертификат эътимод намекунад.

## 3. Ба кор андозед (2 терминал)

**Терминали 1: backend:**
```powershell
cd C:\Users\Asus\ToolShopCRM\backend
$env:ASPNETCORE_ENVIRONMENT = "Development"
$env:Https__Redirect = "false"
dotnet run --project ToolShop.API --urls http://localhost:5252
```

**Терминали 2: frontend бо HTTPS:**
```powershell
cd C:\Users\Asus\ToolShopCRM\frontend\toolshop-client
npm install
npm run dev:lan
```
Он менависад: `Network: https://192.168.1.23:5173/`. Ин суроғаи шумост.

Пеш аз телефон дар худи компютер дар Chrome `https://192.168.1.23:5173` -ро кушоед. **Огоҳии сертификат набояд бошад** (қуфл сабз/бе хато). Агар хато бошад, қадамҳои 1.3 ва 1.4 -ро такрор кунед.

## 4. Дар телефон

1. Дар Chrome (Android) ё Safari (iPhone) кушоед: **`https://192.168.1.23:5173`** (IP-и худро гузоред).
2. Бояд қуфл бе огоҳӣ намоён бошад. Агар «Your connection is not private» бошад, CA дар телефон эътимодшуда нест (қадами 2).
3. Бо логин ва пароли худ ворид шавед (дар чат нанависед).

## 5. Аввалин скан ва фурӯш

**Тайёрӣ (маҳсулот бо штрихкод).** Скан танҳо маҳсулотеро меёбад, ки дар майдони «Barcode» штрихкод дорад. Ду роҳ:

- **А. Ашёи воқеӣ (беҳтарин).** Як ашёи мағозаро гиред. Дар компютер: Маҳсулот → ин маҳсулотро кушоед → дар майдони **Barcode** рақамҳои зери штрихкодро нависед → Нигоҳ доред. Маҳсулот дар анбор бояд ≥ 1 дона бошад (Боқимонда → «Ворид», агар лозим бошад).
- **Б. Тасвири санҷишӣ дар экрани компютер.** Файли `docs\test-ean13-2000000000008.png` -ро дар компютер кушоед. Як маҳсулоти санҷишӣ созед (ном «TEST скан», нарх 1 TJS, Barcode `2000000000008`) ва 5 дона бо «Ворид» илова кунед. Телефонро ба экран нигоҳ доред. Баъд маҳсулотро «ғайрифаъол» кунед (нест накунед).

**Скан:**
1. Дар телефон: **Касса** → тугми кабуди **«Скан бо камера»**.
2. Браузер иҷозати камераро мепурсад → **Allow / Иҷозат**. (Агар «Block» -ро пахш кунед: қуфл → Site settings → Camera → Allow.)
3. Камераи **қафо** кушода мешавад. Штрихкодро 10–20 см дур дошта, дар чорчӯбаи сафед нигоҳ доред. Равшанӣ кофӣ бошад.
4. Бояд сабз шавад: **«Ба сабад илова шуд»**, ном, нарх, «Дар сабад: 1 · Дар анбор: N» ва вибратсия.
5. Штрихкодро дар назди камера нигоҳ доред: миқдор **1** мемонад. Барои дона илова кардан тугми **«Яке дигар»**. Хато шуд, **«Яктоаш гирифтан»**.
6. **«Тайёр»** -ро пахш кунед: сабад кушода мешавад.

**Фурӯш:**
1. Дар сабад муштариро интихоб кунед ё «бе муштарӣ» (walk-in = пардохти пурра).
2. Усули пардохт (нақд) ва «Пурра».
3. **«Анҷоми фурӯш»** → тасдиқ → чек.

**Санҷиш баъд аз фурӯш (дар компютер):**
- **Фармоишҳо:** фармоиш «Completed» бо маҳсулот ва маблағ.
- **Боқимонда:** захира ба миқдори фурӯхташуда кам шуд. Дар **Ҳаракатҳо** сатри «Sale».
- **Пардохтҳо:** пардохти нав. **Қарзҳо:** агар қисман/қарзӣ бошад, бақия.
- **Дашборд / Молия:** Revenue ва Payments Received навшуданд.

**Бекор кардани фурӯши санҷишӣ:** Фармоишҳо → фармоиш → **«Баргардонидани фармоиш»**. Захира бармегардад (SaleReturn), пардохт «Refunded» мешавад. Ҳеҷ чиз нест намешавад.

## 6. Агар кор накунад

| Нишона | Сабаб ва ҳал |
|---|---|
| «Your connection is not private» дар телефон | CA дар телефон насб/эътимод нашудааст (қадами 2). iPhone: Certificate Trust Settings. |
| Саҳифа намекушояд (timeout) | Firewall (1.6), Wi-Fi дигар аст, ё Wi-Fi «Public». IP-ро бо `ipconfig` санҷед. |
| Баъд аз тағйири IP кор намекунад | Сертификат барои IP-и кӯҳна аст. Қадами 1.4 -ро бо IP-и нав такрор кунед ва `npm run dev:lan`-ро аз нав оғоз кунед. |
| Камера «рад шуд» | Қуфл → Site settings → Camera → Allow, баъд саҳифаро аз нав кушоед. |
| «Камера танҳо бо HTTPS кор мекунад» | Шумо `http://` кушодаед. `https://...:5173` кушоед. |
| «Штрихкод ёфт нашуд» | Ин маҳсулот Barcode надорад ё рамз фарқ мекунад. Маҳсулотро кушоед, Barcode -ро ворид кунед. Маҳсулоти нав худкор сохта намешавад. |
| Хонда намешавад | Равшанӣ, 10–20 см, штрихкоди тоза. Ё рамзро дар майдони дастӣ ворид кунед. |
| 502/500 дар воридшавӣ | Backend (терминали 1) кор намекунад. |

## 7. Бехатарӣ ва тозакорӣ

- Dev server ба **шабакаи маҳаллӣ** кушода мешавад. Онро танҳо дар Wi-Fi-и боэътимоди худ истифода баред (на дар кафе/мағозаи кушода).
- Backend ба базаи **асосӣ** `toolshop_crm` пайваст аст: фурӯши санҷишӣ фармоиши воқеӣ месозад (онро баргардонед).
- Баъд аз санҷиш: терминали 2-ро бо `Ctrl+C` бипӯшед.
- Хоҳед, CA-ро нест кунед: дар Windows `mkcert -uninstall`; Android: Settings → Security → Encryption & credentials → User credentials → CA -ро нест кунед; iPhone: Settings → General → VPN & Device Management → профилро нест кунед. Папкаи `frontend\toolshop-client\.certs` -ро нест кунед.
