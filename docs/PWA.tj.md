# ToolShopCRM: PWA (Windows, macOS, Android, iOS)

CRM ҳоло **Progressive Web App** аст: як барнома дар браузер, ки онро метавон ба Windows, macOS, Android ва iOS насб кард. Backend (ASP.NET Core), база (PostgreSQL), нақшҳо, иҷозатҳо ва қоидаҳои тиҷоратӣ тағйир наёфтаанд.

> Ҳолат: тайёр барои санҷиши staging. **Deployment анҷом дода нашудааст.**

## 1. Чӣ илова шуд

- Web App Manifest (`manifest.webmanifest`), иконаҳо (192, 512, maskable 512, `apple-touch-icon` 180).
- Service Worker (Workbox, `vite-plugin-pwa`): танҳо **қолаби статикии барнома** (JS/CSS/HTML/иконаҳо) нигоҳ дошта мешавад.
- Тугмаи «Насби барнома» дар сарлавҳа (Chrome/Edge/Android) ва дастур барои iOS.
- Огоҳии «Пайвастшавӣ нест» ва манъи амалҳои навишт бе сервер.
- Огоҳии «Версияи нав дастрас аст» бо тугмаи «Навсозӣ».
- Мутобиқсозӣ: drawer-и мобилӣ, Касса бо тугмаҳои 44 px ва навори поёнии «Сабад ва пардохт», рӯйхатҳои Фармоишҳо/Анбор/Маҳсулот/Муштариён дар телефон ҳамчун корт.

## 2. Чӣ тавр насб мекунанд

| Платформа | Қадамҳо |
|---|---|
| Windows (Chrome, Edge) | Тугмаи «Насби барнома» дар сарлавҳа, ё нишони насб дар қатори суроға -> «Install». |
| macOS (Chrome, Edge) | Ҳамон тавр. Дар Safari 17+: File -> «Add to Dock» (ин роҳ дар ин лоиҳа санҷида нашудааст). |
| Android (Chrome) | «Насби барнома» ё меню (⋮) -> «Install app» / «Add to Home screen». |
| iPhone / iPad (Safari) | Тугмаи «Мубодила» -> «На экран Домой» / «Add to Home Screen» -> «Илова». iOS API-и насб надорад, бинобар ин тугмаи «Насби барнома» дастурро нишон медиҳад. |

Баъди насб барнома дар тирезаи алоҳида (бе навори суроға) кушода мешавад.

## 3. HTTPS (ҳатмӣ барои насб)

Service Worker ва насб танҳо дар **HTTPS** (ё `http://localhost`) кор мекунанд.

- `http://192.168.x.x:5173` аз телефон: Service Worker ва насб кор **намекунад**. Ин маҳдудияти браузер аст.
- Барои санҷиш аз телефон: сертификати боэътимод (масалан `mkcert`, сертификати корпоративӣ) ё туннели HTTPS.
- Барои staging/production: сертификати воқеӣ дар reverse proxy, HSTS фаъол.
- Frontend ва API бояд ҳарду HTTPS бошанд. Саҳифаи HTTPS ба API-и HTTP дастрасӣ надорад (mixed content).

## 4. Танзим

| Чӣ | Чӣ тавр |
|---|---|
| Суроғаи API дар frontend | `VITE_API_URL` ҳангоми `npm run build`, масалан `VITE_API_URL=/api` (дар паси proxy ҳамон домен) ё `https://api.example.com/api`. Пешфарз: `http://localhost:5252/api`. |
| CORS | `Cors:AllowedOrigins` дар backend (рӯйхати доменҳои frontend, бе wildcard). Агар frontend ва API як домен бошанд, лозим нест. |
| Нишони build | `APP_BUILD_ID` ҳангоми build (масалан `APP_BUILD_ID=2026.10.12-1`); бе он вақти build. Дар поёни Sidebar «build …» нишон дода мешавад. |

## 5. Стратегияи навсозии версия

1. Ҳар build файлҳои JS/CSS-ро бо ҳэш месозад (`assets/…-<hash>.js`). `sw.js` рӯйхати файлҳо ва ҳэшҳояшонро дорад, пас ҳар тағйир `sw.js`-ро тағйир медиҳад.
2. Браузер `sw.js`-ро ҳангоми кушодан ва ҳар **1 соат** (барнома кушода бошад) месанҷад.
3. Версияи нав **худкор ҷорӣ намешавад**: паёми «Версияи нав дастрас аст» бо «Навсозӣ» / «Баъдтар» пайдо мешавад. Саҳифа худ аз худ дубора бор намешавад, пас фурӯши ҷорӣ нопадид намешавад.
4. «Навсозӣ» -> Service Worker-и нав фаъол мешавад -> саҳифа як бор бор мешавад. Кэши кӯҳна тоза карда мешавад.
5. Тафтиш: `npm run verify:update` ду build-и воқеиро месозад (v1 -> v2) ва тафтиш мекунад: v1 насб мешавад, паём пайдо мешавад, саҳифа бе тасдиқ бор намешавад, баъд аз «Навсозӣ» v2 кор мекунад.

**Ҳатмӣ барои сервер (reverse proxy / веб-сервер):**

- `sw.js`, `index.html`, `manifest.webmanifest` бо `Cache-Control: no-cache` (ё `no-store`) дода шаванд. Агар онҳо дар кэш бимонанд, навсозӣ дер мерасад.
- `assets/*` (файлҳо бо ҳэш) бо `Cache-Control: public, max-age=31536000, immutable`.
- Роутҳои SPA ба `index.html` баргарданд (`try_files $uri /index.html`), `/api` ба backend равад.
- `Service-Worker-Allowed` лозим нест: `sw.js` дар реша аст.

Мисоли header-ҳо (танҳо ҳамчун истинод, **дар ин лоиҳа татбиқ нашудааст**):

```nginx
location = /sw.js              { add_header Cache-Control "no-cache"; }
location = /index.html         { add_header Cache-Control "no-cache"; }
location = /manifest.webmanifest { add_header Cache-Control "no-cache"; }
location /assets/              { add_header Cache-Control "public, max-age=31536000, immutable"; }
location /                     { try_files $uri /index.html; }
```

**Тартиби нашр:** аввал backend (бо мутобиқати қафо), баъд frontend. Агар frontend-и кӯҳна бо API-и нав кор кунад, бояд API тағйироти шикастанда надошта бошад. Барои баргардонидан (rollback) build-и қаблиро дубора нашр кунед: Service Worker ҳар тафовутро ҳамчун навсозӣ мебинад.

## 6. Бе пайвастшавӣ (offline): қоидаҳо

**Нигоҳ дошта мешавад (кэш):** танҳо файлҳои статикии барнома (кодҳо, услуб, иконаҳо). Он каме ҳуҷм дорад (тақрибан 1.1 МБ).

**Нигоҳ дошта намешавад:**

- Ягон ҷавоби API: фармоишҳо, пардохтҳо, молия, ҳисоботҳо, муштариён, анбор. Service Worker ҳеҷ қоидаи runtime-кэш надорад ва `/api` ва `/health`-ро ҳеҷ гоҳ ҷавоб намедиҳад.
- JWT (access token): танҳо дар хотираи саҳифа. Дар localStorage, sessionStorage, IndexedDB ё Cache Storage навишта намешавад.
- Маълумоти ҳассос ва молиявӣ дар кэши offline нест.

**Бе сервер иҷро намешавад:** фурӯш (Касса), пардохт, тағйири анбор (воридот/хуруҷ/ислоҳ), баргардонидан, хароҷот ва ҳар амали навиштан. Ҳангоми offline:

- навори зард «Пайвастшавӣ нест» пайдо мешавад;
- тугмаи «Анҷом додани фурӯш» ғайрифаъол аст;
- ҳар дархости навиштан **пеш аз баромадан аз браузер** рад мешавад ва **ба навбат гузошта нашуда**, баъдтар худкор такрор намешавад. Хатогӣ: «Пайвастшавӣ нест. Ин амал … иҷро нашуд».

Хондани саҳифаҳо бе интернет маълумоти кӯҳнаро намоиш намедиҳад: онҳо хатои боркунӣ нишон медиҳанд. Вақте барнома бе интернет кушода шавад, қолаби барнома пайдо мешавад, вале барои ворид шудан ва кор бо маълумот пайвастшавӣ лозим аст.

## 7. Санҷишҳо

```powershell
cd frontend\toolshop-client
npm test                      # Vitest
npm run lint
npm run build
npm run e2e:pwa               # build + PWA/responsive/offline дар 6 профили эмулятсия, бе backend
npm run verify:update         # ҷараёни навсозии версия (v1 -> v2)
```

`e2e:pwa` backend-ро аз ҷониби **mock** иваз мекунад (`e2e-pwa/mockApi.ts`). Он ҷойгузини санҷишҳои воқеии `scripts\Run-E2E.ps1` нест.

Профилҳо (эмулятсия дар Chromium: андозаи экран, touch, User-Agent):

| Профил | Чӣ эмулятсия мекунад |
|---|---|
| `windows-desktop` | 1366×768, UA Windows |
| `macos-desktop` | 1440×900, UA macOS |
| `android-phone` | Pixel 7 |
| `android-tablet` | Galaxy Tab S4 |
| `ios-phone-emulated` | iPhone 14 (Chromium бо UA-и iOS) |
| `ios-tablet-emulated` | iPad (gen 7) |

Барои муҳаррики воқеии Safari (WebKit): `npx playwright install webkit`, баъд `PW_WEBKIT=1 npm run e2e:pwa`. Ин профилҳо дар cloud иҷро нашудаанд.

Скриншотҳо ба `e2e-pwa-shots\<профил>\` навишта мешаванд.

## 8. Маҳдудиятҳои маълум

- Санҷиш дар **дастгоҳҳои воқеӣ** (Windows, macOS, iPhone, iPad, Android) анҷом дода нашудааст; танҳо эмулятсия дар Chromium. Рафтори воқеии Safari/iOS (насб, Add to Home Screen, namoyishi status bar, клавиатура), push, back-gesture дар iOS бояд дар дастгоҳ санҷида шавад.
- iOS: насб танҳо аз Safari (Share -> Add to Home Screen). `beforeinstallprompt` дар iOS нест.
- iOS: агар барнома муддати дароз истифода нашавад, браузер маълумоти сайтро метавонад тоза кунад. Пас аз он бояд аз нав ворид шуд.
- Refresh token дар `sessionStorage` нигоҳ дошта мешавад (рафтори пештара, тағйир наёфт): пас аз пӯшидани тирезаи барнома аз нав ворид шудан лозим мешавад.
- «Мавқуф кардани фурӯш» (Касса) мундариҷаи сабадро (номи маҳсулот, нарх, номи муштарӣ) дар **localStorage**-и ҳамон дастгоҳ нигоҳ медорад (рафтори пештара, на Service Worker). Дар дастгоҳи умумӣ ин рӯйхатро тоза кунед.
- Версия бе тасдиқи корбар фаъол намешавад: агар корбар «Баъдтар»-ро пахш кунад, то дафъаи оянда версияи кӯҳна кор мекунад.
- Нишони насб дар Chrome/Edge вақте пайдо мешавад, ки браузер барнома насбшаванда мешуморад (HTTPS, manifest, Service Worker). Дар `http://localhost` танҳо барои санҷиш.
- Windows/macOS-и воқеӣ: тугмаи «Насби барнома» ва пайдо шудани «Install»-ро дар Chrome/Edge-и воқеӣ санҷед (дар эмулятсия «beforeinstallprompt» сунъӣ фиристода шуд).
