# MFA (санҷиши дуқадама) дар ToolShop CRM

Ин ҳуҷҷат барои соҳиби мағоза ва Admin аст. Дар он ҳеҷ рамз, калид ё рамзи барқарорӣ навишта намешавад. Онҳоро ҳеҷ гоҳ дар чат, почта, скриншот ё ҳуҷҷат нигоҳ надоред.

## Барои кӣ ҳатмист

- **Admin ва Manager:** ҳатмӣ. Бе MFA вориди система шудан мумкин нест.
- **Cashier ва Warehouse:** ҳоло ҳатмӣ нест.

Ҳатмият дар бэкенд ҳам санҷида мешавад, на танҳо дар экран. Токени воридшавӣ бе тасдиқи MFA барои Admin/Manager қабул намешавад.

## Танзими аввал (як маротиба)

Дар воридшавии аввал пас аз фаъол шудани MFA:

1. Номи корбарӣ ва рамзро ворид кунед.
2. Экрани «Танзими санҷиши дуқадама» нишон дода мешавад. Бо барномаи аутентификатор (Google Authenticator, Microsoft Authenticator, Aegis ва монанди инҳо) QR-кодро скан кунед. Агар скан намешавад, калиди матниро дар барнома ворид кунед.
3. Рамзи 6-рақамаи барномаро ворид кунед ва «Фаъол кардан»-ро пахш кунед.
4. **Рамзҳои барқарорӣ** нишон дода мешаванд. Онҳо **танҳо як бор** нишон дода мешаванд. Онҳоро дар ҷои бехатар нигоҳ доред (дафтарча дар сейф, парол-менеҷер). Онҳоро **дар ҳамон телефон** нигоҳ надоред, ки аутентификатор дар он аст.
5. «Ман рамзҳоро нигоҳ доштам»-ро тасдиқ кунед. Баъд сессия оғоз мешавад.

**Муҳим:** то он вақте ки Admin/Manager MFA-ро танзим накардааст, ҳар касе, ки рамзи ӯро медонад, метавонад аввал MFA-ро худаш танзим кунад. Бинобар ин танзимро фавран пас аз фаъолсозӣ анҷом диҳед.

## Воридшавии ҳаррӯза

Номи корбарӣ + рамз, баъд рамзи 6-рақама аз барнома. Барои ворид кардани рамзи барқарорӣ «Рамзи барқарориро истифода баред»-ро пахш кунед. Ҳар рамзи барқарорӣ танҳо як бор кор мекунад.

Баъди 5 рамзи нодуруст пай дар пай, санҷиш барои 5 дақиқа баста мешавад.

## Агар телефон гум шуд ё барнома нест шуд

Тартиб аз осон ба мураккаб:

1. **Рамзи барқарорӣ.** Бо он ворид шавед, баъд MFA-ро аз нав танзим кунед (ё дархост диҳед, ки Admin онро аз нав танзим кунад) ва рамзҳои нав гиред.
2. **Admin-и дигар.** Дар саҳифаи «Users» тугмаи «MFA-ро аз нав танзим кардан»-ро барои корбар пахш кунед. Ин MFA-ро хомӯш мекунад ва корбарро аз ҳама дастгоҳҳо мебарорад. Дар воридшавии оянда ӯ MFA-ро аз нав танзим мекунад. Инро танҳо баъди боварӣ ба он, ки худи ҳамон шахс дархост мекунад, иҷро кунед (масалан, шахсан ё бо занг ба рақами маълум). Admin MFA-и **худро** аз нав танзим карда наметавонад.
3. **Ягона Admin, рамзи барқарорӣ ҳам нест.** Танҳо соҳиби сервер:
   1. Backup гиред: `backend\scripts\Backup-Database.ps1`
   2. `powershell -ExecutionPolicy Bypass -File .\Reset-AdminMfa.ps1 -UserName admin`
   3. Скрипт номи корбарро барои тасдиқ мепурсад. Рамзи PostgreSQL-ро скрипт худаш дар сатри пинҳон мепурсад.
   4. Он MFA-ро хомӯш мекунад, калид ва рамзҳои барқарориро нест мекунад ва ҳамаи сессияҳои корбарро қатъ мекунад. Рамзро тағйир намедиҳад.
   5. Воридшавии оянда MFA-ро аз нав танзим мекунад ва рамзҳои нав мегирад.

Ҳар аз нав танзимкунии Admin дар audit log сабт мешавад (`UserMfaReset`: кӣ ва барои кӣ, бе ягон рамз).

## Танзимоти сервер

- Калид: `Security__MfaRequiredRoles` (рӯйхати нақшҳо бо вергул). Агар танзим нашуда бошад, default `Admin,Manager` аст.
- Берун аз Development/Testing (масалан Production), агар ин рӯйхат Admin ва Manager-ро дар бар нагирад, **барнома оғоз намешавад** ва хатои равшан медиҳад. Бо ин MFA-ро бо иштибоҳ хомӯш кардан имконнопазир аст.
- Дар Development/Testing рӯйхати холӣ ё `none` MFA-ро хомӯш мекунад (барои тестҳо ва E2E). `Run-E2E.ps1` инро худаш мегузорад.
- Дар Windows тағйирёбандаи холӣ нест мешавад, бинобар ин барои хомӯш кардан `none` истифода шавад.

## Хатарҳои маълум (ҳоло)

- Калиди аутентификатор ва рамзҳои барқарорӣ дар PostgreSQL (`AspNetUserTokens`) рамзгузорӣ нашудаанд. Backup ва дастрасӣ ба DB бояд ҳамон тавр муҳофизат шавад, ки ҳешҳои рамзҳо. Рамзгузорӣ вазифаи алоҳида аст.
- Ҳисобкунии кӯшишҳои нодурусти рамзи MFA дар хотираи барнома аст. Агар барнома аз нав оғоз шавад ё чанд нусха кор кунад, ҳисоб аз нав оғоз мешавад. Қулфи ҳисоби корбар (lockout) дар DB боқӣ мемонад.
- Дастрасӣ бе MFA барои Cashier/Warehouse танҳо бо рамз аст.
