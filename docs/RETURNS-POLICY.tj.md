# Сиёсати баргардонӣ ва ҳисоби молиявӣ (вариант C)

Ин ҳуҷҷат қоидаҳои тасдиқшудаи баргардонии мол дар ToolShop CRM-ро тавсиф мекунад.

## Принсипи асосӣ
- Фурӯш дар давраи **фурӯш** мемонад. Баргардонӣ дар давраи **баргардонӣ** сабт мешавад. Давраи гузашта ҳеҷ гоҳ аз нав навишта намешавад.
- Ҳар баргардонӣ сатри тағйирнашавандаи ledger аст (`OrderReturns` + `OrderReturnItems`) бо рақами `RET-000001`, санаи сервер (UTC), корбар ва сабаб. Хатогиро бо амалиёти нав ислоҳ мекунанд, на бо таҳрири таърих.
- Пардохтҳо ҳеҷ гоҳ ба `Refunded` иваз намешаванд ва нест намешаванд. Баргардонидани пул ҳамчун `RefundAmount` дар худи баргардонӣ сабт мешавад.
- Қарз ҳеҷ гоҳ нигоҳ дошта намешавад, ҳамеша ҳисоб мешавад. Захираи анбор аз `InventoryMovement` ҳисоб мешавад.

## Статусҳои фармоиш
`Completed` → `PartiallyReturned` → `Returned`. Ба `PartiallyReturned` ҳам пардохт гирифтан мумкин аст.

## Баргардонии қисмӣ
- Барои ҳар сатр: миқдори баргардонида ва миқдори вайрон.
- Молҳои солим бо ҳаракати `SaleReturn` ба анбор бармегарданд. Молҳои вайрон ба анбор намеоянд (ҳаракат нест).
- Арзиши баргардонида = арзиши сатр бо тақсими пропорсионалии тахфифи фармоиш. Баргардонии охирин боқимондаи рақамкуниро мегирад, то ҷамъ дақиқан ба Total баробар шавад.
- Баргардонии аз боқимонда зиёд рад мешавад (`QUANTITY_EXCEEDS_REMAINING`).

## Баргардонидани пул (refund)
- Refund ≤ маблағе, ки мизоҷ зиёд пардохтааст: `max(0, (пардохт − refundҳои гузашта) − (Total − арзиши баргардонидашуда))`.
- Агар нишон дода нашавад, ҳамон ҳадди боло гирифта мешавад. Усул: аз пардохти охирин, ё интихоби корбар.
- Фурӯши қарзӣ: агар мизоҷ қарздор бошад, баргардонӣ қарзро кам мекунад ва refund 0 мешавад.
- Бекор кардани пардохте, ки боқимондаро аз refund-шуда паст мекунад, рад мешавад (`VOID_BELOW_REFUNDED`).

## Формулаҳои молиявӣ (барои давраи P)
| Нишондиҳанда | Формула |
|---|---|
| Revenue | Σ Total-и фурӯшҳо (аз рӯи `OrderDate`) − Σ арзиши баргардонида (аз рӯи `ReturnedAt`). Метавонад манфӣ бошад, ба 0 маҷбур намешавад. |
| COGS | Σ (миқдор × `CostAtSale`) − Σ (`RestockedQty` × `CostAtSale`-и баргардонӣ дар P) |
| Write-off (memo) | Σ (`WrittenOffQty` × `CostAtSale`). Дар COGS мемонад ва дубора ҳисоб намешавад. |
| Payments Received | Σ пардохтҳои дуруст (аз рӯи `CreatedAt`) − Σ `RefundAmount` (аз рӯи `ReturnedAt`) |
| AR (дар лаҳза) | Σ `max(0, Total − арзиши баргардонида − (пардохт − refund))` |

- Арзиши номаълум (`null`) ҳеҷ гоҳ ба 0 табдил намешавад: UI «N/A» нишон медиҳад.
- Фоизи margin барои Revenue ≤ 0 ба 0 мемонад (маблағҳо манфӣ мемонанд).
- `completedOrdersCount` шумораи фурӯшҳои анҷомёфтаро мешуморад, AOV = фурӯши умумӣ / ин шумора.

## Мисолҳои рақамӣ (нархи аслӣ 60, нарх 100, фурӯхта 5, баргардонӣ 2 ба маблағи 200)
| Ҳолат | Revenue | COGS | Фоидаи умумӣ дар давраи баргардонӣ |
|---|---|---|---|
| A: ҳарду солим | −200 | −120 | **−80** |
| B: ҳарду вайрон | −200 | 0 | **−200** (write-off 120) |
| C: яктои солим, яктои вайрон | −200 | −60 | **−140** (write-off 60) |

## Корҳои дар оянда
- C5: бастани давраи молиявӣ (`FinancialPeriodClose`).
- F2: гурӯҳбандии рӯзҳо аз рӯи UTC+5 (ҳоло UTC).
- Базаи воқеӣ танҳо пас аз backup ва тасдиқи алоҳида migrate мешавад (`AddOrderReturns`).
