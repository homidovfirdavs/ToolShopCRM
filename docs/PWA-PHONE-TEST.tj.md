# Санҷиши PWA дар телефони воқеӣ (Android ва iPhone)

Мақсад: санҷиши он чизҳое, ки эмулятсия нишон дода наметавонад (насби воқеӣ, Add to Home Screen, клавиатура, touch, режими офлайн).

> Ин дастур ҳамчун санҷиши **staging**-и муваққатӣ аст. Production deployment нест.

## 0. Чаро HTTPS лозим аст

Service Worker ва насб дар телефон танҳо бо **HTTPS** кор мекунанд. `http://192.168.x.x:5173` аз телефон кор **намекунад**. Роҳи содда: туннели HTTPS бо як суроға барои frontend ва API (`/api` ба backend фиристода мешавад, CORS лозим нест).

## 1. Омодагӣ (як бор)

Cloudflare Tunnel (ройгон, бе ҳисоб):

```powershell
winget install --id Cloudflare.cloudflared
```

Баъд терминалро пӯшед ва дубора кушоед.

## 2. Ба кор андозед (3 терминал)

**Терминал 1: backend** (ҳамон база ва User Secrets-и муқаррарӣ):

```powershell
cd C:\Users\Asus\ToolShopCRM\backend
$env:ASPNETCORE_ENVIRONMENT = "Development"
$env:Https__Redirect = "false"
dotnet run --project ToolShop.API --urls http://localhost:5252
```

**Терминал 2: frontend** (build бо `/api` ва preview; proxy ба `localhost:5252` дар `vite.config.ts` танзим шудааст):

```powershell
cd C:\Users\Asus\ToolShopCRM\frontend\toolshop-client
$env:VITE_API_URL = "/api"
npm run build
npm run preview -- --port 4173
```

**Терминал 3: туннел:**

```powershell
cloudflared tunnel --url http://localhost:4173
```

Cloudflared суроғаи `https://<номи-тасодуфӣ>.trycloudflare.com` менависад. Онро дар телефон кушоед.

Пеш аз телефон дар компютер санҷед: суроғаро дар Chrome кушоед, `/health/ready` бояд 200 диҳад.

## 3. Хавфсизӣ (ҳатмӣ хонед)

- Суроға тасодуфӣ аст, аммо ҳар кӣ онро донад, саҳифаи воридшавиро мебинад. Маълумот танҳо баъди воридшавӣ дастрас аст ва rate limit фаъол аст.
- Дар ин санҷиш backend ба базаи **асосии** `toolshop_crm` пайваст аст. Фурӯши санҷишӣ фармоиши воқеӣ месозад. Бинобар ин ё танҳо хондан/офлайнро санҷед, ё як фурӯши санҷишӣ кунед ва баъд онро «Баргардонидан» кунед (фармоиш ва баргардонидан дар таърих мемонанд, нест намешаванд).
- Пароли худро дар чат нанависед. Дар телефон худатон ворид шавед.
- Баъди санҷиш терминали 3-ро бо `Ctrl+C` пӯшед: суроға фавран кор намекунад.
- Туннел кори production нест.

## 7. Навсозии версия (ихтиёрӣ)

1. Дар терминал 2 бо `Ctrl+C` preview-ро қатъ кунед.
2. `$env:APP_BUILD_ID = "test-2"; npm run build; npm run preview -- --port 4173`
3. Дар телефони насбшуда барномаро кушоед: бояд «Версияи нав дастрас аст» пайдо шавад. «Навсозӣ» пахш кунед: «build test-2» дар Sidebar.

## 8. Агар кор накард

| Нишона | Сабаб | Чӣ кунед |
|---|---|---|
| Тугмаи насб нест (Android) | HTTPS нест, ё аллакай насб шудааст | Суроға `https://` бошад; нишони кӯҳнаро нест кунед |
| `Blocked request. This host is not allowed` | Домени туннел дар `allowedHosts` нест | Дар `vite.config.ts` → `preview.allowedHosts` домени туннелро илова кунед |
| Воридшавӣ хатои шабака медиҳад | Backend (терминал 1) кор намекунад ё build бе `VITE_API_URL=/api` сохта шуд | Терминал 1-ро санҷед, build-ро бо `/api` дубора кунед |
| Тағйири код дида намешавад | Service Worker версияи кӯҳнаро нигоҳ медорад | Дар барнома «Навсозӣ»; ё Chrome → Site settings → Clear data |
| iPhone: насб нест | Chrome истифода шудааст | Safari истифода баред |

## 9. Натиҷаро фиристед

Ҷадвалҳои боло (№ → PASS/FAIL) ва скриншоти хатоҳоро фиристед. Ман танҳо он чизеро PASS мегузорам, ки шумо дар дастгоҳ дидед.
